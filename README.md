# Job

Next.js App Router website using TypeScript and plain CSS. Requires Node.js 20.9 or newer.

## Local development

```sh
npm install --no-package-lock
npm run dev
```

Open http://localhost:3000.

To update your local copy, run `git pull --ff-only origin main` from the project folder. If dependencies have changed, run `npm install --no-package-lock` again.

`npm run build` creates a production build.
